# 製作順序與驗收

目前只執行步驟 1–2：公開 repository 與四畫面靜態樣稿。畫面確認關卡前不接續資料功能。

| 步驟 | 內容 | 通過條件 |
| --- | --- | --- |
| 1 | 確認 GitHub 帳號、建立 repository、保存規格 | 帳號與名稱正確，公開專案，無私人資料 |
| 2 | 首頁、月曆、單日、記事編輯樣稿 | 手機畫面入口清楚，按鈕／留白／表單可檢查 |
| 3 | 日期規則、台灣今天判定、導覽 | 範圍、無效日期與返回測試通過 |
| 4 | 新增、單日查看、保存再開啟 | 第一條記錄流程可完整使用 |
| 5 | 修改、移日、刪除 | 同日多筆，取消不誤改資料 |
| 6 | 草稿 | 中斷恢復，正式內容與草稿分開 |
| 7 | 備份、預覽、合併還原 | 往返、衝突、重複匯入、失敗安全 |
| 8 | 首頁本週記事 | 週界線、排序、空白週、今天正確 |
| 9 | 月曆與單日切換 | 年月、標記、返回狀態正確 |
| 10 | 找日期 | 直達有效日期，清楚提示錯誤 |
| 11 | 算天數 | 兩種结果、交換、返回保留內容 |
| 12 | 節日來源整理與介接 | 年度官方資料核對，缺年提示 |
| 13 | 視覺與貓咪互動完成 | 一致、可讀、不干擾、減少動態 |
| 14 | 全面驗收修正 | 無未解決資料遺失或日期錯算 |
| 15 | 正式 Pages 與交付 | 實際網址可用、紀錄完整 |

每步依序完成必要依賴，使用小幅可回復提交。關卡：步驟 2 後由使用者確認畫面；步驟 7 後檢查資料可靠性；步驟 14 後檢查發布條件。本次可先發布明確標示的樣稿，並非正式 V1 完工。

## 驗收

- 日期：同日、跨月年、閏年、反向、1900／2100 邊界；2024-02-28 至 03-01 相隔 2 天、2025 年同區間 1 天、2100-02-29 無效。
- 台灣今天：裝置其他時區及台灣午夜前後；記事日期不移動。
- 記事：多筆、純文字／表情／心情、新增修改移日刪除、取消。
- 保存與草稿：重新整理、關閉再開、編輯中斷；不能誤報成功。
- 失敗：模擬保存不可用／容量不足，輸入可取回；還原寫入失敗保持現有資料。
- 備份：乾淨環境往返、重複、衝突、損壞、不支援版本。
- 導覽：各入口、瀏覽器返回、重新整理定位。
- 節日：官方年度檔逐項核對；未收錄年提示。
- 手機：320、375、390、430px，較大平板／桌面；長文、放大、鍵盤、安全區、無橫向溢出。
- 可存取性：鍵盤、焦點、表單標籤、對比、減少動態。
- Pages：部署紀錄、HTTP、子路徑資源、四畫面、正式功能流程。
- iOS Safari／Android Chrome 實機列入最終驗收；無實機時標示未驗證，不能以桌面手機模擬替代實機聲明。

## 交付

公開 repository、Pages 網址、可編輯原始碼、規格、操作／備份說明、資料來源及驗收紀錄。只在真實驗證後標示功能完成。
