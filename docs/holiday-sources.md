原始下載檔位於 `assets/holidays/source/`；`taiwan.json` 保留官方日期、是否放假（0＝上班，2＝放假）及完整備註。來源網址、原始檔 SHA-256、版本、筆數、核對日期皆內附於 JSON。`python scripts/build-holidays.py` 可由原始檔重建。網站只載入本站靜態 JSON，不向外部日曆 API 送出個人資料。

轉換不補造節日名稱或補假原因。官方備註「補假」直接顯示補假；「補行上班」顯示調整上班。無備註的週六日放假顯示週末；無備註且放假的平日顯示調整放假。節日本日若在週末，仍顯示節日名稱與週末標籤。2025-05-01 此年度政府日曆為上班日，2026、2027-05-01 則收錄勞動節；不以另一年度規則回填歷史日期。

測試逐項對照三份 CSV 的全部 1,095 天，包括星期、放假狀態、備註；另外驗證補假、調整上班、跨年補假與缺年。未收錄年份清楚提示；檔案載入失敗提示重試，不顯示「沒有節日」。

官方修訂需人工重新下載、核對、重建並部署；本站不宣稱自動更新。核對時請選資料集最新修正版，更新腳本的來源與核對日期後執行 `npm test`。
