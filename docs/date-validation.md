# 日期與台灣節日驗收

版本 0.3.0，日期 2026-10-10。畫面及資料驗收已獲使用者確認，本次驗收找日期、算天數、月曆年月與台灣節日；尚非手機實機全面驗收通過。

## 請使用者試用

1. 首頁「找日期」輸入 2024-02-29 → 單日顯示星期四 → 返回月曆顯示 2024 年 2 月。查有記事的日期時應能看見既有記事。空白或 2101-01-01 提示錯誤，保留輸入。
2. 月曆直接選 2027 年 12 月，重新整理仍保留月份；點一天後返回，仍在原月份。上／下月、回今天可用，1900 年 1 月不能再往前。
3. 月曆下方「兩個日期，相隔幾天？」：同日結果 0／1；2024-02-28 到 03-01 為 2／3；2025 年相同區間為 1／2。查看兩端日期後返回與重新整理，輸入仍在。
4. 開始日 2026-10-11、結束日 2026-10-10：提示反向，沒有錯誤天數；按交換後結果為 1／2，兩個日期換位。
5. 查 2025-02-08「補行上班」；2026-10-09「補假」；2026-10-10「國慶日＋週末」；2027-12-31「補假」。2024 年會清楚提示未收錄節日。可查 [官方年度檔](https://data.gov.tw/dataset/14718) 比對。
6. 原本的記事、草稿、備份／還原照常使用。此次只加入日期與節日功能，資料 key 與備份版本均未更動。

## 已完成工程驗證

- 23 項 Node 測試：既有資料保存 13 項、日期 5 項、日期工具 2 項、節日 3 項。節日測試逐項對照原始官方 CSV 的全部 1,095 天、星期、狀態與備註；檔案缺日、錯誤狀態會拒絕載入。
- 真實瀏覽器：找閏日、缺年提示、超範圍與空白、直達單日並定位月曆、直接選年月／重新整理、反向交換、同日、跨閏日、兩端查看返回、補行上班／補假／跨年補假。
- 修正並回歸驗證月曆返回捲動：手機寬 390px，離開前 411px，進入工具 0px，返回月曆仍為 411px；原月份 URL 亦保留。重新整理保留日期／月份，捲動位置僅保留在目前分頁的頁面生命週期。
- 節日故障測試使用獨立本機副本：缺少 JSON 顯示失敗及重試入口；提供檔案後重試恢復。日期與記事畫面不被阻斷。
- 4 畫面（找日期、算天數、月曆、長節日名稱單日）× 7 寬度（320／375／390／430／768／1024／1440px）無橫向溢出；320px 月曆日期格寬 44.28px。正常本機頁面無 console error／warn。
- 所有測試輸入均使用本機測試資料，未將記事上傳 GitHub 或正式網站。

## 邊界

節日為截至核對日的靜態官方檔，非即時更新，不代替個人班表。日期計算包含週末與假日，無工作天功能。iOS Safari／Android Chrome 實機、手機軟鍵盤與最終全面發布驗收仍需後續執行。雲端登入同步尚未啟用。
