# 貓咪手帳 V1 定稿

確認日期：2026-10-10（台灣時間）。使用者已確認規格、樣稿及步驟 3–7 的資料驗收，授權接續找日期、算天數與節日。本階段完成步驟 8–12 的功能及必要導覽，停在日期與節日驗收。雲端同步僅提出後續方案，尚未啟用。

## 目標

個人、手機優先的生活記事與心情行事曆。早上看本週記事、安排活動時查日期、睡前記錄生活與心情。快速記錄、容易找回為核心；療癒感與互動不干擾操作。

## 首頁

週一到週日、切換上一週／下一週、回到本週。記事按日期由早到晚分組，同日依建立順序舊到新；修改不改排序。無記事的日期省略，今天永遠顯示。摘要與選填心情可開啟詳細內容。三個主要入口：記一筆、看月曆、找日期。資料與備份為次要入口。

## 月曆與單日

年月選擇、上／下月、回到今天；週一在最左側。今天外框、有記事小點與圖例，月曆格子不塞長文。找日期與算天數可由月曆進入。

單日使用獨立畫面，顯示日期、星期、今天標示、節日／補假／調整上班資訊與所有記事；前／後一天、新增。無記事有空白提示。返回保留週／月份與位置。V1 不放農曆。

## 日期

日期功能範圍 1900-01-01 至 2100-12-31。今天固定以 Asia/Taipei 判定。記事所屬日期不隨裝置時區移動。

找日期預設今天，支援輸入／選擇。有效日期直達單日並定位月曆；無效或超出範圍則提示且保留輸入。

算天數完成兩日期後自動顯示「相隔天數」（不計起日、計入迄日，同日 0）與「頭尾都算」（同日 1）。按日曆日期處理跨月、年、閏年，包含週末與假日。迄日較早提示並提供交換，不自動交換。查看兩端日期後返回保留輸入。

## 記事與心情

同日多筆，不用標題，不做完成勾選；準備做的事與已發生的事用文字記錄，不自動判定完成。欄位：日期、記事文字、表情（選填）、心情文字（選填）。後三項至少填一項，允許只記心情。

首頁新增預設今天，單日新增預設選定日期，可改日期。正式內容按儲存才更新；成功返回並提示。修改日期移動記事，修改不改排序。刪除前確認日期與摘要，無垃圾桶；刪除同步移除對應編輯草稿。儲存失敗保留輸入且不顯示成功。

## 草稿、保存與備份

新記事一份草稿，既有記事各自保留編輯草稿。自動暫存，重入可繼續／捨棄；儲存成功或明確捨棄才清除對應草稿。區分草稿已暫存與正式已儲存。

localStorage 保存在目前瀏覽器，不自動同步。首次保存簡短提醒，資料設定保留完整說明；清除網站資料可能失去記事，無痕模式不適合長期保存。

JSON 備份含記事、草稿、格式版本。還原先驗證格式／日期／欄位／版本，預覽新增、略過、衝突數，再確認寫入。相同 ID 相同內容略過；不同內容保留兩份、標示匯入副本。匯入草稿不直接取代目前編輯內容，保留可恢復草稿。重複匯入同份備份不持續產生副本。無效檔案或寫入失敗不得破壞現有資料。舊備份可能恢復已刪除記事，預覽時提醒。備份未加密，提醒妥善保存。

## 台灣節日

先收錄 2025–2027 年，主要來源 https://data.gov.tw/dataset/14718 ，依官方年度 CSV 整理靜態 JSON，保留來源、版本、核對日期。區分週末、節日本日、補假、調整上班。以政府行政機關日曆為參考，不代替個人班表。官方修訂時核對、更新並重新發布，不宣稱自動更新。未收錄年份清楚提示，日期記事功能仍正常。其他生活節日有實際需求再加入。

## 視覺與互動

溫暖手帳：米白、暖棕、鼠尾草綠、少量杏桃色。正文至少 16px，主要按鈕約 48px；日期觸控以至少 44×44px 為目標，手機安全區與鍵盤不遮必要操作，狀態不只靠色彩。

貓咪角色在頁首不遮內容，點擊才出現預先準備的短句與輕微動作。不自動彈出、不播放聲音、不打卡、不根據心情下判斷。支援減少動態效果。

## 技術與部署

HTML、CSS、原生 JavaScript；個人資料 localStorage；年度節日為內附 JSON，無需外部 API。公開 GitHub repository `cat-days`，網站名稱「貓咪手帳」。Pages 從 main 根目錄發布，處理 repository 子路徑與重新整理定位。只提交程式、素材、節日與文件；記事、草稿不由網站上傳到 GitHub。

## 範圍外

會員、雲端同步、資料庫、完成勾選、農曆、工作天計算、小遊戲、推播與時間提醒。

## 實作約定

使用語意 HTML、CSS 語意色彩變數、具可辨識名稱的按鈕。動態文字使用安全的文字輸出；避免將記事解讀為 HTML。日期與資料邏輯配合有意義的測試；畫面修改以真實瀏覽器確認。完整 V1 與本階段完成範圍分開記錄，不提前跨越使用者驗收關卡。
