## 請使用者確認

在公開網站的相同瀏覽器進行以下小流程；可將記事文字加上「測試」，避免與平常記事混淆。

1. 同一天存兩筆：一筆文字、一筆只選心情。重新整理確認仍在。
2. 修改其中一筆，換到明天，確認原日期減少、新日期增加；編輯時返回不會改掉正式內容。
3. 新開記事寫一句但不按儲存，返回後重開，選「繼續草稿」確認文字；捨棄草稿確認正式記事不受影響。
4. 首頁「資料與備份」下載 JSON。刪除一筆測試記事，再選該備份，先確認預覽新增數量，再確認還原。再次選相同備份，確認沒有額外副本。
5. 確認手機上心情選擇、儲存、刪除提醒、草稿繼續和備份入口易讀易按。

本關卡需要使用者確認資料保存與操作符合預期。確認後才接續步驟 8–15。
